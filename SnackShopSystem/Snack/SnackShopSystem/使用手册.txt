一、系统概述
零食商店购物系统是一个完整的 B2C 电商平台，支持用户注册登录、浏览零食商品、加入购物车、生成订单、模拟支付、查看订单历史，以及管理员后台管理商品和订单。系统界面简洁，操作直观，适合毕业设计演示。

主要功能模块
角色	功能
普通用户	注册/登录、查看商品列表、加入购物车、修改购物车数量、删除购物车项、提交订单、模拟支付、取消待支付订单、查看我的订单
管理员	商品管理（增删改查、上下架）、查看所有用户订单、后台仪表盘

三、快速部署与启动（5分钟上手）
3.1 下载源码并导入 IDEA
将 SnackShopSystem.zip 解压到本地目录（路径不要包含中文或空格）。

打开 IntelliJ IDEA，选择 File → Open，选中解压后的文件夹，点击 OK。

IDEA 会自动识别为 Maven 项目，并开始下载依赖（首次加载可能需要 3~5 分钟，请保持网络通畅）。

3.2 创建数据库并初始化数据
启动 MySQL 服务（Windows 可在服务中启动 MySQL80；Mac 可使用 brew services start mysql）。

使用 MySQL 客户端（如 Navicat、DataGrip 或命令行）执行以下命令：

sql
CREATE DATABASE IF NOT EXISTS snack_shop_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE snack_shop_db;
将项目根目录下的 database.sql 文件中的全部 SQL 语句复制到客户端中执行。该脚本会创建表结构并插入示例商品、管理员账号及普通用户账号。

3.3 修改数据库连接配置
打开 src/main/resources/application.properties 文件，修改以下两行：

properties
spring.datasource.username=root          # 改为你的 MySQL 用户名
spring.datasource.password=你的密码       # 改为你的 MySQL 密码
其他配置无需改动。

3.4 运行项目
在 IDEA 中找到主类 SnackShopApplication.java，右键选择 Run 'SnackShopApplication'。

等待控制台输出 Started SnackShopApplication in X.XXX seconds 表示启动成功。

打开浏览器访问：http://localhost:8080/login

3.5 默认测试账号
角色	用户名	密码
普通用户	user1	password123
管理员	admin	password123
密码已通过 BCrypt 加密，这些账号在 database.sql 中已预置。你也可以通过注册功能创建新用户。

四、用户端操作指南
4.1 注册新用户
在登录页面点击 注册账号。

填写用户名、密码、真实姓名、收货地址、手机号（均为必填）。

点击 立即注册，成功后自动跳转至登录页。

4.2 登录系统
输入用户名和密码，点击 登录。

普通用户登录后进入首页（/index）；管理员登录后进入后台仪表盘（/admin/dashboard）。

4.3 浏览商品
登录后点击顶部导航栏 所有商品，进入商品列表页。

商品以卡片形式展示，包含图片、名称、价格、库存。

可以按分类（后续可扩展）或直接滚动查看全部上架商品。

4.4 加入购物车
在商品卡片下方，输入购买数量（默认1，最大不超过库存），点击 加入购物车。

系统会提示添加成功（无弹窗，直接刷新页面或跳转，可在购物车中查看）。

4.5 管理购物车
点击顶部导航栏 购物车，查看已添加的商品。

修改数量：在数量输入框中修改数字，点击 更新 按钮，小计和总金额会变化。

删除商品：点击对应商品的 删除 按钮，该商品从购物车移除。

若购物车为空，页面会提示“去逛逛”。

4.6 生成订单
在购物车页面，确认商品无误后，点击 去结算。

进入确认订单页面，系统自动带出当前登录用户的收货信息（姓名、手机、地址），可手动修改。

点击 提交订单，系统会扣减商品库存、清空购物车、生成订单，并跳转到支付页面。

4.7 模拟支付
在支付页面显示订单号，点击 确认支付。

系统将订单状态从“待支付”更新为“已支付”，并跳转到 我的订单 列表。

注意：本系统为模拟支付，不涉及真实资金流转。

4.8 取消订单
在 我的订单 页面，只有状态为“待支付”的订单可以取消。

点击对应订单的 取消订单 按钮，确认后订单状态变为“已取消”，同时系统会自动恢复该订单中商品的库存数量。

4.9 查看历史订单
登录后点击顶部导航栏 我的订单，即可查看所有已下单记录（包含待支付、已支付、已取消状态）。

点击订单卡片可查看详情（收货信息、商品明细等）。

4.10 退出登录
点击顶部导航栏 退出，系统将清除会话并返回登录页。

五、管理员端操作指南
5.1 登录后台
使用管理员账号（admin / password123）登录，系统会自动识别角色并跳转到管理后台首页 /admin/dashboard。

5.2 后台首页
显示两个管理入口：商品管理、订单管理。

5.3 商品管理
点击 商品管理，进入商品列表页（/admin/products）。

新增商品：点击 + 新增商品 按钮，填写商品名称、分类、价格、库存、描述、图片URL、状态（上架/下架），保存。

图片URL可以是网络图片地址（如 https://xxx.jpg），也可以是本地路径（如 /images/xxx.jpg，需将图片放在 src/main/resources/static/images/ 下）。

编辑商品：在列表中找到要修改的商品，点击 编辑，修改信息后保存。

删除商品：点击 删除 按钮，确认后删除该商品（注意：如果该商品已有订单，删除后订单明细中的商品名称仍保留，但商品本身不再显示）。

5.4 订单管理
点击 订单管理，查看所有用户的订单记录，包含订单号、用户ID、收货人、总金额、状态、下单时间等。

管理员不能修改订单状态，仅用于监控。

六、常见问题与解决（FAQ）
Q1: 启动时提示 Project 'org.springframework.boot:spring-boot-starter-parent:2.7.14' not found
原因：Maven 本地缓存损坏或网络问题。
解决：关闭 IDEA，删除 C:\Users\你的用户名\.m2\repository\org\springframework\boot 整个文件夹，重新打开项目并刷新 Maven。建议配置阿里云镜像。

Q2: 访问页面出现 Whitelabel Error Page 或 500 错误
可能原因与解决：

数据库未启动：启动 MySQL 服务。

表不存在：重新执行 database.sql。

端口冲突：修改 application.properties 中的 server.port=8080 为其他端口。

Q3: 登录后一直跳回登录页（无限循环）
原因：Spring Security 配置中要求认证，但某些页面未放行。
解决：检查 SecurityConfig.java 中 .antMatchers("/css/**", "/js/**", "/images/**", "/register", "/doRegister", "/login", "/").permitAll() 是否包含所有静态资源和注册页面。

Q4: 商品图片不显示
原因：图片URL配置错误或图片文件不存在。
解决：

若使用网络图片，确保URL可访问。

若使用本地图片，将图片文件放入 src/main/resources/static/images/，并在数据库 image_url 字段中填写 /images/文件名.jpg。

也可以留空，系统会显示灰色占位图。

Q5: 加入购物车时提示库存不足
原因：购买数量超过了商品的当前库存。
解决：减少数量或等待管理员补货（管理员可在后台修改库存）。

Q6: 取消订单后库存没有恢复
原因：代码逻辑已实现恢复，若未恢复可能是订单状态不是“待支付”或系统异常。
解决：检查订单状态，确保为“PENDING”。若仍有问题，请查看控制台错误日志。

Q7: 如何修改管理员密码？
由于密码使用 BCrypt 加密，不能直接修改数据库明文。可以通过程序注册一个管理员账号，然后修改数据库 role 字段为 ADMIN；或者使用在线 BCrypt 生成器生成新密码的哈希值，更新到 user 表。

Q8: 系统能否部署在服务器上？
可以。将项目打包成 JAR 文件（mvn clean package），然后使用 java -jar target/SnackShopSystem-1.0.0.jar 运行。确保服务器上安装 JDK 17 和 MySQL，并修改配置文件中的数据库连接地址。

七、附录：Maven 阿里云镜像配置（加速依赖下载）
如果依赖下载缓慢或经常失败，请按以下步骤配置：

找到 Maven 的 settings.xml 文件：

Windows: C:\Users\你的用户名\.m2\settings.xml（若不存在则新建）

Mac/Linux: ~/.m2/settings.xml

在 <mirrors> 标签内添加：

xml
<mirror>
    <id>aliyunmaven</id>
    <mirrorOf>central</mirrorOf>
    <name>阿里云公共仓库</name>
    <url>https://maven.aliyun.com/repository/public</url>
</mirror>
在 IDEA 中刷新 Maven 项目即可。
